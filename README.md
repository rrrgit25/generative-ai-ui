# Rath GPT

This project is a React-based user interface for a generative AI application that can generate text, images, audio, and videos. It includes features for chatting and editing prompts, providing a comprehensive platform for users to interact with generative AI technologies.

## Features

- **Chat Interface**: Users can communicate with the AI through a chat interface, allowing for real-time interaction.
- **Prompt Editing**: Users can edit prompts to customize the output generated by the AI.
- **Content Generation**: The application supports the generation of various content types:
  - Text
  - Images
  - Audio
  - Videos
- **Settings Panel**: Users can adjust settings related to the generative AI to tailor the experience to their needs.

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd generative-ai-ui
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```

## Deployment (AWS free tier)

Production runs on AWS within free-tier limits:

- CloudFront and S3 serve the React SPA.
- A single-node **k3s** Kubernetes cluster on EC2 runs the Spring Boot backend, deployed with **Helm**.
- **Terraform** provisions all infrastructure.
- **GitHub Actions** builds, scans and deploys, using keyless OIDC.
- CloudWatch alarms provide auto-recovery, and AWS Budgets plus an uptime probe cover SRE alerting.

| Path | Contents |
|---|---|
| `infra/terraform/bootstrap` | Remote state bucket (one-time) |
| `infra/terraform/app` | VPC, EC2 + k3s, ECR, S3, CloudFront, SSM, IAM/OIDC, alarms, budget |
| `deploy/helm/genai-backend` | Helm chart (probes, PVC, NetworkPolicy, hardened securityContext) |
| `deploy/remote-deploy.sh` | On-node deploy: SSM → Secret sync, Helm upgrade with auto-rollback |
| `.github/workflows` | CI, Deploy, Terraform checks, uptime probe |
| `docs/OPERATIONS.md` | Setup steps, SLOs, alerts, runbooks, cost profile |
